# React Flow 전체 적용 점검 · 2026-10-04

## 범위와 수정

프론트엔드 전체 TSX의 구성도·단계 흐름 사용처를 점검했습니다. FlowSection을 사용하는 앱 파일 56개와 디자인 패턴 23개 상세 페이지가 공유하는 BookPatternContent를 포함합니다. 모든 페이지를 브라우저로 하나씩 검증한 것은 아니며, 전체 소스 검사와 공통 구현별 대표 화면 검증을 구분합니다.

- 남아 있던 `orientation="vertical"` 지정 32곳을 제거했습니다. 단일 흐름·비교 흐름·디자인 패턴에 동일한 자동 방향 규칙을 적용합니다. 5단계는 실제 캔버스 영역이 1,200px 이상이면 가로이며, 좁은 비교 열과 모바일은 세로입니다. 6단계 이상은 세로를 유지합니다.
- 가상 대기실, 로드밸런싱, 샤딩·복제, Kafka 파티션 선택·복제 배치, Saga/Outbox의 별도 구성도에 `motion="flow"`를 지정했습니다. 연결선 재생·정지 버튼과 방향 안내 문구를 제공합니다. 모든 선의 동시 이동은 실제 실행 순서나 트래픽을 의미하지 않습니다.
- SystemDiagram과 LearningFlowCanvas는 공통 `useDiagramMotion`으로 화면 밖·숨겨진 탭·동작 줄이기 설정을 반영합니다. 순차 FlowSection은 현재 단계의 다음 간선만 움직입니다.
- 그래프 BFS/DFS의 방문 순서 카드 목록을 FlowSection으로 교체했습니다. 반환된 순서를 5개씩 나누어 선택·재생하며, 원본 그래프의 간선 및 실시간 실행과 구분합니다. 방문 결과는 생략하지 않고 인접 리스트·단계 로그도 보존합니다.
