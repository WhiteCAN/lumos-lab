# Lumos Lab 제품 요구사항

## 제품과 사용자 문제

Lumos Lab은 Java·웹 개발·데이터·메시징·AI 구조를 설명, 시각화, 실행 실습과 소스 디버깅으로 연결하는 학습용 웹사이트입니다. 개념을 읽는 것만으로는 입력에 따라 코드가 어떻게 동작하는지 이해하기 어려운 문제를 해결합니다.

대상은 Java·Spring·프론트엔드·시스템 설계를 학습하거나 복습하는 개발자입니다. 상용 회원 서비스나 실제 AI 서비스 운영을 현재 제품의 완성 상태로 설명하지 않습니다.

## 핵심 기능과 이용 흐름

1. 사이드바 또는 검색으로 학습 주제를 찾습니다.
2. 개념·비교표·코드·흐름 또는 시스템 구성도를 읽습니다.
3. 실습 입력을 바꾸고 실행해 요청·응답·실패를 확인합니다.
4. 안내된 구현 파일과 메서드에 브레이크포인트를 두어 관찰합니다.
5. 학습 완료를 표시하고 관련 주제로 이동합니다.

현재 기능에는 중앙 학습 목록과 검색, 로컬 학습 진행도, 공통 API 실습 패널, 브라우저 실행 예제, FlowSection, React Flow 구성도가 있습니다. 페이지 등록 원본은 [study-pages.ts](../frontend/src/lib/study-pages.ts), 실습 연결은 [debug-lab-catalog.ts](../frontend/src/lib/debug-lab-catalog.ts)를 기준으로 합니다. 페이지 수를 이 문서에 중복 관리하지 않습니다.

## 콘텐츠 요구사항

- 새로운 주제 정리는 설명 페이지와 입력을 바꿀 수 있는 실행 실습을 기본으로 합니다. 기존 API·실습을 우선 재사용합니다.
- 요청·응답·로딩·오류와 디버깅 위치를 안내합니다.
- 브라우저 실행, 서버 실행, 로컬 모형, 실제 외부 인프라를 구분합니다.
- 대표 실습이 설명 전체를 실행한다고 표현하지 않으며 입력 제한과 생략 기능을 명시합니다.
- 한국어 제목·설명을 사용하고 메뉴·검색·탭 제목을 일치시킵니다.
- 모바일에서도 설명과 실습을 읽고 조작할 수 있어야 합니다.

## 완료 판단 기준

라우트·검색 등록 누락이 없고, 관련 실습 연결 검사와 변경 영역의 테스트·빌드가 통과해야 합니다. 대표 정상·실패 입력, 모바일 넘침, 키보드 조작을 실제 화면에서 확인합니다. 정량적인 사용률·학습 성과 목표는 아직 정하지 않았으며 임의 수치를 목표나 달성 결과로 적지 않습니다.

## 현재 범위 밖과 후속 과제

실제 회원 로그인·리프레시 토큰·사이트 간 인증은 [후속 JWT 과제](future-jwt-auth.md)입니다. 실제 운영용 OAuth, Kafka 클러스터, Redis 분산 락, 외부 LLM·벡터 검색은 학습 페이지나 모의 API가 존재한다는 이유로 구현 완료로 간주하지 않습니다. 후속 DB 학습 범위는 [DB·CRUD·JPA 계획](future-db-crud-jpa.md)에서 관리합니다.

요구사항 변경은 이 문서, 표현 규칙은 [디자인 시스템](DESIGN_SYSTEM.md), 구현 구조는 [아키텍처](ARCHITECTURE.md)에 반영합니다.
