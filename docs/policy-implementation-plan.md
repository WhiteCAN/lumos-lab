- 갱신일: 2026-10-19. 고정 TODO 번호를 유지하며 상태 변경은 공통 TODO를 먼저 갱신한다.

- 실행 순서: **6-B 실제 DB 검증 → 15 위치정보·파일 보호 → 19 신고 처리**. 이후 4/22/23/6, 16→17→18, 20/21, 24→25를 의존성에 맞춰 진행한다.
- 새 기능을 기존 개발 게시물에 소급 적용하지 않는 결정은 유지한다. 법적 파기 의무나 현재 접근권한 문제까지 면제하는 뜻은 아니다.

## Lab 적용 범위

실제 로그인 도입 작업을 시작할 때 이 연결 목록을 확인한다. 현재 공개 학습 서비스의 메뉴·보안·데이터 구조는 변경하지 않는다. Photo TODO 15~21·24를 Lab 기능 과제로 자동 추가하지 않는다. 이번 문서 갱신은 실제 공통 로그인·탈퇴·자료 내보내기 도입이 아니다.
