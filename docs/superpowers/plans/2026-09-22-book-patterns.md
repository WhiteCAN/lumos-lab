# 책 예제 기반 디자인 패턴 학습·API 실습 계획

목표: 제공된 『Java 언어로 배우는 디자인 패턴 입문 3판』 23장 예제를 실제 코드에 근거해 정리하고 API로 디버깅한다.

구성: 기본 Sample의 역할·흐름과 대표 Q/A 차이를 한국어로 설명한다. 기존 5개 패턴 URL은 유지해 책 예제를 추가하고, 나머지 18개 패턴 페이지를 만든다. 기존 개요에 책 순서의 목차를 추가한다.

- [x] 1~8장 원본 분석·API 구현·테스트·학습 데이터.
- [x] 9~16장 원본 분석·API 구현·테스트·학습 데이터.
- [x] 17~23장 원본 분석·API 구현·테스트·학습 데이터.
- [x] 공통 요청 검증·API 라우팅·페이지와 메뉴·검색 연결.
- [x] 원본 MIT 고지 보존, GUI·파일·무한 반복의 HTTP용 변경점 설명.
- [x] 전체 테스트·lint·build, 23개 API 기본 입력 및 오류·모바일 화면 검증.
- [x] README·작성 지도·인계 문서 갱신.

원본 경로는 읽기 전용으로 취급하며 프로젝트에 개인 PC 경로를 기록하지 않는다. API에서 원본 Main을 실행하지 않고 제한된 입력과 요청별 상태로 패턴 객체의 실제 협력을 실행한다.

## 검증 결과

- 백엔드 전체 테스트 77개 통과.
- 프론트엔드 학습 검색·API 실습 테스트 17개, lint, 정적 빌드 통과.
- 브라우저에서 23개 장의 API 실행 모두 HTTP 200 및 성공 응답 확인.
- Interpreter 실행량 제한 위반 HTTP 400 및 오류 결과 표시 확인.
- 책 목차 23개 링크, 검색 후 페이지 이동, 375px 화면의 가로 넘침 없음 확인.
