# 미통합 학습 작업 통합 기록

- 대상: `codex/navigation-search-titles`의 `5414111`을 `development`에 병합.
- 포함: 책 디자인 패턴 23장과 API, 페이지 검색·주제별 메뉴·진도, 컬렉션 실행 기록, 기존 미통합 학습 페이지.
- 이번 릴스 페이지 4개를 중앙 목록에 등록하여 메뉴·검색·진도에 포함. 새 공통 페이지 인터페이스에 맞추고 기존 학습 API를 연결했다. Docker 실습은 작은 검증 파이프라인이며 실제 이미지 빌드나 크기 측정은 하지 않는다.
- 충돌 해결: 최신 DB 프로필 분리·필수 JWT 비밀값 설정·팀 메뉴 정책·의존성 버전과 GenAI 설명/좌우 배치를 유지했다.
- 보관된 stash의 소스 파일은 모두 통합 작업에 존재한다. 컬렉션 원본·기록·생성/검증 스크립트는 동일하며 나머지 페이지는 중앙 제목/메뉴 구조로 갱신된 버전이다. 브라우저 캡처와 예전 계획을 포함한 stash는 안전을 위해 그대로 보관한다.
- 검증: 백엔드 전체 테스트, 프론트엔드 lint, study/labs/team-navigation 테스트, 컬렉션 실제 Java 기록 검증, production build 통과.
- 브라우저: Iterator API 실행 HTTP 200 및 책 3개 순회 결과, Docker 검색에서 새 페이지 2개와 CI/CD 검색 결과 확인.
- 통합 범위는 로컬 `development`다. 원격 푸시·운영 브랜치 반영·배포는 이 작업에서 수행하지 않았다.
