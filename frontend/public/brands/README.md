# 브랜드 아이콘 출처

이 폴더는 학습 콘텐츠에서 제품을 식별하기 위한 SVG만 보관합니다.

- 제공: [Devicon](https://devicon.dev/)의 `original` SVG. 프로젝트 라이선스는 MIT이며 원문은 `LICENSE-DEVICON.txt`에 보관합니다.
- 각 아이콘의 다운로드 URL, 고정한 저장소 커밋과 SHA-256은 `sources.json`에 기록합니다.
- 배포된 SVG 파일을 수정 없이 저장합니다. 원본의 다색 채움·명암·형태를 유지하며 별도 `fill`, CSS 필터 또는 대표 색상을 덧씌우지 않습니다.
- Redis·React·Spring·Docker·Apache Kafka·PostgreSQL·Kubernetes·GitHub를 식별하는 용도로만 사용합니다. 서비스의 자체 로고나 제휴·보증 표시로 사용하지 않습니다.
- 제품 로고의 권리는 해당 소유자에게 있습니다. Devicon의 사용 조건과 개별 브랜드 지침을 따릅니다. `original`은 Devicon의 버전 이름이며 항상 최신 브랜드 리뉴얼 버전임을 뜻하지는 않습니다.
- 외부 CDN 없이 로컬 파일을 제공합니다. 아이콘 업데이트 시 SVG와 메타데이터·라이선스를 함께 확인합니다.

애니메이션은 자체 CSS와 React 상태 로직으로 구현하여 Motion 또는 React Flow 의존성을 추가하지 않았습니다. 해당 라이브러리의 핵심 코드는 MIT 라이선스이며 Motion+·React Flow Pro는 별도 유료 상품입니다.
